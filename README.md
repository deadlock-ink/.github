# .github

Shared files for the Deadlock Ink organization.

- `profile/README.md`: the text shown on the organization page.
- `CODE_OF_CONDUCT.md`, `CONTRIBUTING.md`, `SECURITY.md`: used by every repository of the organization that does not have its own copy.
- `.github/ISSUE_TEMPLATE/` and `.github/PULL_REQUEST_TEMPLATE.md`: default templates for issues and pull requests.

This repository is public on purpose (GitHub requires it for the organization profile). Do not put anything private here.

---

Спільні файли організації Deadlock Ink: текст профілю, кодекс поведінки, правила внеску, політика безпеки та шаблони issue і pull request. Репозиторій публічний навмисно, тому приватного тут нічого не зберігаємо.
