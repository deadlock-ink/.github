# Security Policy

## Reporting a vulnerability

Please do not report security problems in a public issue, pull request or discussion.

Use GitHub's private vulnerability reporting on the affected repository (the "Report a vulnerability" button on its Security tab). If that is not available, contact us through [abyssc0re.com](https://abyssc0re.com) and say only that you have a security report; we will arrange a private channel.

Please include:

- what is affected and how to reproduce the problem,
- what an attacker could do with it,
- your contact details, if you want a reply.

## What to expect

We read every report, reply when we can, and fix confirmed problems as soon as we reasonably can. We cannot promise exact dates. We will credit you if you want to be credited.

## Please do

- Test only on your own accounts and data.
- Give us a reasonable time to fix the problem before telling anyone else.

## Please do not

- Access, change or delete other people's data.
- Run denial-of-service tests or send spam.

# Політика безпеки

## Як повідомити про вразливість

Будь ласка, не повідомляйте про проблеми безпеки у публічних issue, pull request чи обговореннях.

Скористайтеся приватним повідомленням про вразливість на GitHub у відповідному репозиторії (кнопка «Report a vulnerability» на вкладці Security). Якщо її немає, зв'яжіться з нами через [abyssc0re.com](https://abyssc0re.com) і напишіть лише, що маєте звіт про безпеку: ми домовимося про приватний канал.

Додайте, будь ласка:

- що саме вражено і як це відтворити,
- що могла б зробити зловмисна людина,
- ваші контакти, якщо хочете отримати відповідь.

## Чого чекати

Ми читаємо кожне повідомлення, відповідаємо, коли можемо, і виправляємо підтверджені проблеми щойно це розумно можливо. Точних термінів не обіцяємо. Якщо захочете, вкажемо вас у подяках.

## Просимо

- Перевіряти лише на власних акаунтах і даних.
- Дати нам розумний час на виправлення, перш ніж розповідати комусь іще.

## Не слід

- Отримувати доступ до чужих даних, змінювати чи видаляти їх.
- Влаштовувати DoS-перевірки чи розсилати спам.
